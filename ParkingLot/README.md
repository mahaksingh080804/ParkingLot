# Parking Lot System (Java)

Simple console application to park vehicles, calculate fees and view a report.

## Features
- Park Bike / Car / Truck in the first free slot (10 slots)
- Duplicate plate number check
- Exit a vehicle and calculate the fee (Bike Rs.20, Car Rs.40, Truck Rs.80 per hour)
- Show slots, find a vehicle, earnings report

## Concepts used
Classes and objects, encapsulation, arrays, loops, methods, input validation.

## How to run
Open this folder in IntelliJ IDEA, open `ParkingLot.java` and click the green Run arrow next to `main`.
